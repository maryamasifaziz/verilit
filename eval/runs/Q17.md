# How are machine learning models used for network intrusion detection?

## Literature review

Machine learning-based network intrusion detection systems (NIDS) utilize a variety of techniques and algorithms. Studies have evaluated intrusion detection systems using methods such as fuzzy logic, artificial neural networks, and decision trees [1, 2]. Specifically, the decision tree algorithm demonstrated the highest accuracy of 0.992 alongside the lowest false positive rate of 0.009 on the KDD99 dataset [2]. Other investigated models include variants of the Bayesian algorithm, where experimental results indicate test and train accuracies of 69.9% and 71% for the Bernoulli variant, 31.2% and 31.2% for the Multinomial variant, and 81.69% and 82.84% for the Gaussian variant, respectively [5].

To evaluate these models, researchers commonly use publicly available synthetic and converted benchmark datasets. Key metrics utilized in these evaluations include accuracy and F1 score [3]. Widely used benchmark datasets and variants feature NetFlow-based feature sets such as UNSW-NB15, BoT-IoT, ToN-IoT, and CSE-CIC-IDS2018 [4], alongside others like KDD 99 [1], NSL-KDD, and CICIS2017 [7].

Despite these advancements, deploying machine learning for network intrusion detection faces notable limitations and challenges. Popular intrusion detection datasets—including NSL-KDD, CICIS2017, and UNSW-NB15—suffer from issues like class imbalance and antiquated attack methods [7]. Furthermore, persistent challenges in IoT environments encompass dataset quality, real-world generalizability, computational resource constraints that affect edge deployment, and a lack of model explainability [6].

# How does knowledge distillation compress large neural networks while preserving accuracy?

## Literature review

Knowledge distillation compresses large neural networks to achieve model acceleration and compression through various primary methods and algorithms [1, 2]. One prominent approach is counterclockwise block-wise knowledge distillation (CBKD), which divides both the teacher and student models into multiple sub-network blocks to transfer intermediate-layer knowledge from a teacher sub-block to the corresponding student sub-block [1]. Another technique is weight distillation, which transfers knowledge contained in large network parameters via a parameter generator [2]. 

Teacher-student architectures significantly impact the accuracy and performance of the compressed models [3, 4]. By utilizing multi-layer hidden state distillation, the KD-NAS student model attains a 7x speedup on CPU inference and a 2x speedup on GPU relative to an XLM-Roberta Base Teacher, while preserving 90% of the performance [3]. Furthermore, when distilling a ResNet-152 teacher into a ResNet-34 student on ImageNet-1K, the resulting top-1 accuracy spans from 71.6% to 74.0% across five distinct configurations [4]. 

To assess these distilled models, various benchmark datasets and evaluation metrics are employed [5, 6]. For instance, DD-RobustBench assesses distilled datasets on ImageNet-1K using adversarial attack methods such as PGD and AutoAttack [5]. Additionally, frugal knowledge distillation tests its entropy-based data selection approach on benchmark datasets including CIFAR-10, MNIST, and FashionMNIST [6]. 

Despite these successes, current limitations and failure modes persist in deep learning applications [7]. Specifically, in cross-modal settings, conventional knowledge distillation methods face major challenges arising from data and statistical heterogeneities, which result in problems like distillation path selection and knowledge drift [7].

# How does retrieval-augmented generation reduce hallucination in large language models?

## Literature review

Retrieval-augmented generation (RAG) integrates external knowledge through various mechanisms and architectures. One study proposes a decentralized software architecture where the retrieval, augmentation, and generation components are operated independently by distributed entities via an External Retrieval Interface protocol [1]. Additionally, the Domain-Collection-Document (DCD) domain-oriented design structures knowledge and controls query processing through hierarchical decomposition, multi-stage routing, smart chunking, and hybrid retrieval [2]. 

To measure hallucination reduction, an ensemble-based preprocessing framework achieves a 44.3% reduction in hallucination rates on the HaloQuest dataset, which is measured by Natural Language Inference scores using SelfCheckGPT [3]. However, the factual accuracy of generated outputs is directly impacted by the relevance and quality of the retrieved context. Poor-quality retrieved contexts containing irrelevant or noisy information compromise the effectiveness of RAG in addressing large language model hallucinations [4]. Furthermore, under misleading context conditions, models frequently copy incorrect information, which directly impacts factual accuracy [5]. 

Despite these methods, RAG systems face several limitations, failure modes, and computational challenges. They suffer from limitations inherent to information retrieval systems and reliance on large language models, presenting seven failure points across case studies in research, education, and biomedical domains [6]. Moreover, in Corrective Retrieval Augmented Generation (CRAG), an explainability analysis reveals key failure modes, including domain transfer limitations on science questions [7].

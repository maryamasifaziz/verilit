# How effective are deep learning methods for malware detection?

## Literature review

Deep learning methods have demonstrated high effectiveness for malware detection across various architectures and techniques. Commonly used models include hybrid architectures like CNN-LSTM [1, 8], Auto-Encoders combined with Deep Neural Networks [2], Inception v3 feature extraction coupled with Support Vector Machines (SVM) [3], and Recurrent Neural Networks (RNN) [4]. These techniques frequently utilize public and standard datasets such as Malimg, Microsoft BIG2015, Drebin, CICAndMal2017, Malicia, CIC-MalMem-2022, and the Windows PE Malware Dataset [1, 2, 5, 6]. Additionally, specific studies have evaluated detectors on a dataset of 138,047 samples [3] as well as balanced IoT datasets comprising 500 malware and 500 goodware samples [4].

Reported performance results indicate that deep learning malware detectors achieve exceptional metrics. A system using Auto-Encoders and Deep Neural Networks over the Malicia dataset achieved an accuracy of 99.21% and a False Positive Rate of 0.19% [2]. Furthermore, hybrid CNN-LSTM models achieve detection rates of up to 98.7% [1], an RNN model achieved an accuracy of 99.19% on fresh IoT malware samples [4], and a model combining Inception v3 feature extraction with SVM classification reached an accuracy of 99.89% [3].

Despite their high accuracy, these methods face notable limitations, vulnerabilities, and adversarial risks. Adversarial and data poisoning attacks compromise the reliability and accuracy of learning algorithms in cybersecurity applications including malware detection, intrusion detection, and spam filtering [7]. Specifically, gradient-based and optimization-driven attacks against hybrid CNN-LSTM classifiers reveal significant susceptibility under adversarial pressure [8].
